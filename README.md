# Hidrovia Game

Jogo/simulador educacional de gerenciamento logístico ambientado na **Hidrovia Tietê-Paraná**.

## Sobre o projeto

O jogador assume o papel de um operador logístico e precisa transportar cargas entre:

**São Simão (GO)** → **Pederneiras (SP)** → **Porto de Santos**

O objetivo é equilibrar custo, prazo, integridade da carga e emissão de CO₂, enfrentando eventos reais da operação hidroviária como estiagem, eclusas e tráfego.

## Funcionalidades

- Sistema de contratos diários
- Formação de comboio (empurrador + barcaças)
- Gerenciamento de combustível e integridade do casco
- Eventos dinâmicos (estiagem, greve na eclusa, tráfego)
- Eclusa de Nova Avanhandava
- Transbordo multimodal (hidrovia → ferrovia)
- Sistema de reputação e progressão
- Loja/Oficina (melhorias)
- Salvamento local de progresso
- Ciclo de dias

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API
- Web Storage API (localStorage)

## Como executar

1. Clone o repositório ou baixe os arquivos
2. Abra o arquivo `index.html` no navegador
3. Ou use a extensão **Live Server** no VS Code

## Controles

- **W / S** ou **↑ / ↓** → Leme
- **A / D** ou **← / →** → Acelerador
- **P** → Pausar
- **M** → Mutar som
